# 4-Bit-Microprocessor
A complete 4-bit microprocessor design with an integrated FSM Control Unit, ALU, and RAM, simulated via Verilog HDL.


  This project details the complete structural design, functional implementation, and simulation verification of a custom 4-bit Microprocessor Architecture developed using Verilog HDL. Heavily inspired by the classic SAP-1 (Simple-As-Possible 1) computer model, the processor features a central bus-oriented topology designed to clearly illustrate internal hardware synchronization, data routing, and control unit operations.The microarchitecture is constructed from distinct hardware components connected via a shared 4-bit internal data bus: a 4-bit Program Counter (PC), a Memory Address Register (MAR), an integrated 16×8-bit RAM matrix initialized with instruction bytes, an Instruction Register (IR), an Accumulator (Register A), a temporary auxiliary B Register, and a combinational Arithmetic Logic Unit (ALU) capable of performing hardware additions and subtractions.A micro-programmed Finite State Machine (FSM) acts as the system control unit. Driven by an automated sequence ring counter spanning six master clock cycles ($T_1$ to $T_6$), the control unit choreographs the execution pipeline. During the fixed Fetch Phase ($T_1, T_2, T_3$), the system fetches the next instruction address, increments the PC, and transfers opcode bytes from RAM into the Instruction Register. During the variable Execution Phase ($T_4, T_5, T_6$), the FSM decodes the 4-bit custom Instruction Set Architecture (ISA) mapping—including NOP (No Operation), LDA (Load Accumulator), ADD (Addition), SUB (Subtraction), OUT (Output Data), and HLT (System Halt)—and fires precisely timed control words across the computational core.To validate behavioral integrity and data path synchronization, the entire architecture was verified using an HDL simulation testbench framework. The compiled system waves confirm deterministic logic transfers from the internal memory matrix onto the shared system bus channels, successful hardware calculation updates within the accumulator, and the expected step-by-step state cycling of the control engine, fulfilling all criteria for standard educational microprocessor deployment.
